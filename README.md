# 🎙️ EdgeTTS Pro Master

Мощное десктопное приложение на Python для пакетной генерации аудиокниг, словарей и проверки произношения. Поддерживает онлайн-синтез (через Microsoft Edge TTS) и полностью автономный оффлайн-режим.

## 🚀 Ключевые возможности
* **Мульти-движок:** Поддержка онлайн голосов (Edge TTS) и оффлайн голосов (Piper, Windows SAPI5).
* **Умная пакетная обработка:** Автоматическая нарезка файлов EPUB, PDF и TXT на главы.
* **Аудио-эффекты (FX):** Автоматическая вставка маркеров конца предложений (Apollo Quindar, европейский ZVEI Selcall, классическое ретро).
* **Сведение аудио:** Наложение фоновой музыки с автоматическим приглушением (Ducking).
* **Создание аудиословарей:** Пакетная генерация билингвальных словарей из таблиц CSV/Excel.
* **Видео-рендер:** Автоматическая генерация MP4 с обложкой книги для публикации на YouTube (аппаратное ускорение NVIDIA/AMD).

## 🛠️ Установка и запуск (для разработчиков)

1. Склонируйте репозиторий:
   git clone https://github.com/Ainaline2001/EdgeTTS-Pro.git

2. Установите зависимости:
   pip install eel edge-tts beautifulsoup4 ebooklib PyMuPDF pandas openpyxl pypiwin32
   
3. Важно: Для работы программы скачайте и поместите в корневую папку файлы ffmpeg.exe и piper.exe (для оффлайн-режима).
   
4. Запустите скрипт:
   python main.py

Компиляция в .exe
Для создания самостоятельного исполняемого файла используйте PyInstaller:
pyinstaller main.py --hidden-import bottle_websocket --add-data "web;web" --onefile --noconsole --name EdgeTTS_Pro
